* Orgzly Revived

Orgzly 是一款用于记笔记、管理待办清单的大纲（outliner）应用。Orgzly Revived 是社区维护版本，因为原版 Orgzly 的开发已经停止。原版 Orgzly 源码可在[[https://github.com/orgzly/orgzly-android][此处]]找到。

使用 Orgzly，你可以把以纯文本保存的笔记本与移动设备上的目录、SD 卡、WebDAV 服务器或 Dropbox 进行同步。

笔记本以 /Org mode/ 的文件格式保存。“Org mode 用于快速而高效的纯文本记录：记笔记、维护 TODO 清单、规划项目、撰写文档。”更多信息见 http://orgmode.org 。

Orgzly Revived 项目旨在延续 Orgzly 应用的开发。由于原 Orgzly 作者的消失，社区不得不寻求新的方案，因而更名。我们计划持续添加实用功能、修复缺陷、跟进技术演进，并总体上维护 [[https://orgmode.org/][Org Mode]] 在 Android 上的推广与支持。Orgzly Revived 是社区维护版本，原版应用的开发已不再活跃。

* 本 Fork 的改动（AI 与大纲增强）

本仓库是 [[https://github.com/orgzly-revived/orgzly-android-revived][Orgzly Revived]]（GPLv3）的个人 Fork，增加了 AI 辅助任务规划与若干大纲/体验改进。完全兼容 Org 文件格式，并保持上游行为。

** 新增功能

- *AI 任务分解（“AI 分解”）*：长按某个笔记，通过任意 OpenAI 兼容接口自动生成“一层”子任务。每次可现场设置子任务数量与可选的“微调提示词”，支持重新生成；发送给 AI 的上下文可包含标题、祖先进程链与正文。
- *AI 完善*：将整棵笔记子树（标题 + 正文）发给 AI，预览确认后用返回的 Org 大纲整体替换。
- *今日视图作为启动页*：分组显示“逾期 / 今天截止 / 今天计划 / 今日循环”（循环任务带 1 年活跃期），显示完成进度与时间统计（EFFORT / 秒表），分组浅色填充、迷你进度条、一键完成、下拉刷新与设置入口。
- *大纲色阶*：长按顶层节点选择主题色，其子树按层级用同色相阶梯色填充，柔和自然、不刺眼。
- *手动秒表*：每个笔记可开始/停止计时（熄屏安全），父行显示子树合计，仅存于私有 =:PROPERTIES:=，不影响文件格式。
- 小组件美化、SAF 仓库路径解码、日历导出、以及其他修复。

* 校验 APK 签名

以下是 APK 签名证书的 SHA-256 校验和，可用于验证你下载的 APK，工具如 [[https://github.com/soupslurpr/AppVerifier][AppVerifier]] 或 [[https://developer.android.com/tools/apksigner][apksigner]]：

#+begin_quote
com.orgzlyrevived 6F:C9:C2:E2:2D:07:D2:5C:E7:7E:2E:96:34:55:05:3C:38:B8:31:8A:1A:24:91:B3:ED:95:D5:0C:BA:85:49:3D
#+end_quote

你还应确认该校验和与 [[https://orgzlyrevived.com/docs#verify-apk-signature][orgzlyrevived.com]] 上公布的一致。

安装 APK 后，Android 将拒绝把应用升级到任何未使用同一私钥签名的新版本。

* 构建与测试

如果你不使用 Android Studio，并希望从命令行[[https://developer.android.com/studio/build/building-cmdline.html][构建]]和[[https://developer.android.com/studio/test/command-line.html][测试]]应用，可使用标准的 Gradle 任务。例如：

- ~./gradlew build~ 构建项目并生成 APK
- ~./gradlew connectedAndroidTest~ 运行设备端（instrumented）单元测试

请确保为你的测试设备[[https://developer.android.com/training/testing/espresso/setup][关闭动画]]。
